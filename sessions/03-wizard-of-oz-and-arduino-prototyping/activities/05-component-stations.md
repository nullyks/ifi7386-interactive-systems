# Activity 05 - Component Stations

[← Session 3](../README.md) · [← Previous activity](04-button-to-led-loop.md)

**Time:** 20 minutes · **Format:** guided component comparison

## Goal

Find a plausible sensing or actuation option for the team's project and identify what must be checked before building it.

## Part 1 - Sensors (10 minutes)

Inspect the available components or their source diagrams. Choose one candidate and complete the first row. If possible, read an instructor-prepared sensor value in Serial Monitor. A sensor reading is evidence about a physical quantity; it is not automatically a reliable decision about a person's intent.

| Project event or quantity | Candidate component | Signal or reading | Calibration, placement, or uncertainty |
|---|---|---|---|
|  |  |  |  |

Source examples: [force and bend](https://github.com/nullyks/Arduino-erinevad-andurid/blob/main/materjalid/1_FSR_t%C3%BC%C3%BCpi_andurid.md), [TMP36 temperature](https://github.com/nullyks/Arduino-erinevad-andurid/blob/main/materjalid/2_TMP36_temperatuuriandur.md), [HC-SR04 distance](https://github.com/nullyks/Arduino-erinevad-andurid/blob/main/materjalid/3_HC-SR04_kaugusandur.md), [PIR motion](https://github.com/nullyks/Arduino-erinevad-andurid/blob/main/materjalid/4_PIR_t%C3%BC%C3%BCpi_andurid.md), [DHT22 temperature and humidity](https://github.com/nullyks/Arduino-erinevad-andurid/blob/main/materjalid/5_DHT22_andur.md), and [soil moisture](https://github.com/nullyks/Arduino-erinevad-andurid/blob/main/materjalid/6_mullaniiskusandur.md).

## Part 2 - Movement and power (10 minutes)

If the project requires movement, choose by the required motion: continuous rotation, target angle, or controlled steps. Record the load, driver, power source, and what could happen if motion is blocked. Inspect an instructor-prepared setup or diagram; only wire a motor when the correct driver and power supply are available and the instructor has checked the circuit.

| Required movement | Motor candidate | Driver and power needs | First safe test |
|---|---|---|---|
|  |  |  |  |

Source examples: [DC motors](https://github.com/nullyks/Arduino-mootorid-ja-toide/blob/main/materjalid/1_Alalisvoolumootorid.md), [servos](https://github.com/nullyks/Arduino-mootorid-ja-toide/blob/main/materjalid/2_Servomootorid.md), and [stepper motors](https://github.com/nullyks/Arduino-mootorid-ja-toide/blob/main/materjalid/3_Samm-mootorid.md). The [motors and power overview](https://github.com/nullyks/Arduino-mootorid-ja-toide) explains external power and common ground.

## Output

One sensor or input option, one output or movement option, and the specific unknowns that must be resolved before committing to the Hi-Fi build.
