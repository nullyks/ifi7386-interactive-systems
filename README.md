# IFI7386.DT Foundations for the Development of Interactive Systems

Student learning materials for **IFI7386.DT Foundations for the Development of Interactive Systems**.

This repository is the course's shared learning space. Open the current session during class, follow the material from top to bottom, and use the linked activity pages when prompted. New sessions will be added here as the course progresses.

> [!IMPORTANT]
> **Current session:** [Session 1 — User Needs and Initial Project Concept](sessions/01-user-needs-and-initial-project-concept/README.md)

## How to use this repository

- During class, keep the current session page open and follow its sequence.
- Open an activity link when the class reaches that point.
- Record team decisions and project evidence in your team's own shared workspace.
- Return after class for the task, examples, definitions, and public readings.
- Treat early project statements as hypotheses. Preserve earlier versions when evidence changes your thinking.

## Course project

The course project develops over several meetings. Each team will move from an initial user-and-context hypothesis towards an integrated interactive-system prototype supported by design reasoning and evidence.

The first concept must have:

- one real and reachable primary user;
- one specific context and meaningful user goal;
- one problem or unmet need stated without embedding the preferred solution;
- at least one meaningful physical or sensed input;
- at least one perceivable physical or digital output or feedback channel;
- a safe, non-safety-critical, testable scope;
- one complete main interaction before additional features are added.
